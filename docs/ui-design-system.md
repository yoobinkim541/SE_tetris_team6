# 화면 디자인 시스템

크리스털 밤하늘. 기본 Swing 창·사각 버튼·Dialog 글꼴은 화면용으로 쓰지 않는다.
개발용 `DevRttPanel`, `BattleDemo`만 예외다. P2P 로비는 별도 담당이다.

## 글꼴

- 제목·메뉴 버튼: Black Han Sans (`GameTheme.display`). 없으면 Do Hyeon.
- 본문·라벨: Do Hyeon (`GameTheme.text`).
- 숫자·시간·HP: Black Han Sans (`GameTheme.digits`). 0~9 자릿 폭이 같고 0에 빗금이 없다. Orbitron 0 대체는 쓰지 않는다.
    - 한 글자라도 안 보이면 문자열 전체를 바꾸지 말고 글자 단위로 대체한다. `canDisplay`가 참이어도 시각 경계가 비거나 화살표가 줄기뿐이면 못 그린 것으로 본다. `UiKit.drawInAsset` / `drawInBox` / `drawIconText`가 이 경로를 탄다.
- 버튼 글자는 안쪽 폭에 맞게 줄인다. 선택 상태는 조금 더 밝고, 커짐은 아주 작다.
- 14px 이하 보조 글자는 외곽선 없이 둔다.

## 간격

- 8px 단위. 라벨과 캡슐 사이만 4~6px.
- 패널 안쪽 여백은 같은 화면에서 동일.
    - 글자는 글리프 시각 경계(`가Ag0`은 글꼴·크기별 기준)의 중심을 칸 중심에 둔다 (`UiKit.drawInBox`). 제목 효과는 1px 그림자만큼 잉크 중심을 되돌린다. 칸은 에셋 원본의 안쪽 분수다.
- 칸은 정수 크기, 원점은 반올림. 미리보기는 차지한 칸의 중심.

## 부품

- 밤 배경·프레임·탭·알약 버튼·캡슐·배너는 `UiKit`.
- 같은 그림의 하늘색/분홍/보라 변형은 파일이 있으면 파일, 없으면 `AssetStore.imageOrTint`.
- 원본이 표시 크기보다 작아도 깨지지 않게 비율로 자른다. 9등분 모서리는 원본 크기의 비율이다.
- 제목·메뉴 글자: `GameTheme.paintTitle` / `UiKit.paintTitle`. 단색(흰색 또는 옅은 하늘색)과 얇은 남색 외곽선, 아주 약한 그림자. 그라데이션·글로우·하이라이트 띠는 쓰지 않는다. 캐시 키는 문자열·크기·스타일(0 보통, 1 선택)이고 상한은 48장. 14px 이하는 효과 없이 그린다. 레이드 화면도 같은 메서드를 쓴다. 콤보·T-SPIN도 그라데이션 없이 같은 단색이다.
- 숫자 0은 타원이 아니다. 숫자 전용 글꼴의 0 그대로다. 블록 O는 본문 글꼴의 O다.

## 대전

- 이름과 점수는 프레임 위 nametab 하나.
- 받을 공격은 회색 X 칸 10줄. 먼저 들어올 줄이 맨 아래. 보드 프레임에 이어 붙이고 보드 쪽 화살. 라벨 `받을 공격 n/10`.
- 세로 경고 막대는 보조 단서다. 줄 모양을 대체하지 않는다.
- 결과·기권·일시정지는 유리 패널과 알약 버튼. `JOptionPane`을 쓰지 않는다.

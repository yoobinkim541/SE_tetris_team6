# 사용자 2명 실제 플레이 평가 기록지

상태: **미진행**. 2026-10-26 사용자가 미진행임을 확인했다. 자동 테스트·AI 시뮬레이션은 실제 사용자 평가 인원에 포함하지 않는다.

## 준비

동일한 검증 커밋의 Windows ZIP을 새 폴더에 풀고 EXE로 실행한다. 평가자별로 기존 설정·점수 유무를 기록하고, 실제 사용자 데이터를 초기화하기 전 평가자에게 알린다. 평가자 식별은 이름 대신 A/B를 사용해도 된다.

| 항목 | 평가자 A | 평가자 B |
|---|---|---|
| 일시 | 미입력 | 미입력 |
| 평가자 식별 | 미입력 | 미입력 |
| 커밋 / ZIP 이름 / SHA-256 | 미입력 | 미입력 |
| Windows / 해상도 / 배율 | 미입력 | 미입력 |
| Java 별도 설치 없이 실행 | 미확인 | 미확인 |
| 실제 플레이 시간 | 미입력 | 미입력 |
| 최종 결과 | 미평가 | 미평가 |

## 수행 시나리오

## 평가자 피드백

- A: 조작 이해도 / 아이템 설명 이해도 / 불편했던 점 / 개선 제안 — 미입력
- B: 조작 이해도 / 아이템 설명 이해도 / 불편했던 점 / 개선 제안 — 미입력

완료 조건: 서로 다른 2명의 실제 기록, 필수 경로 확인, 발견한 P0/P1 결함 0건 또는 수정·재검증 증거, 평가자 결과 확인. 미관찰 항목은 보충 플레이 후 갱신한다.

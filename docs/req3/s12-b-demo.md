### 수정한 결함: 경기 중 조작 키 안내를 읽을 수 없음

- 현상: 경기 화면 아래 한 줄 키 안내가 화면 폭에 맞춰 줄어 기본 창에서 약 7 px 글자가 됐고, 방향키가 `Left/Right/Down/Up` 영어 이름으로 나왔다. 처음 하는 사람이 키를 찾을 수 없다.
- 수정: 키 안내를 각 보드 옆(공격 대기열 아래)에 18 pt로 옮기고 방향키는 `← → ↑ ↓`로 쓴다. 로컬 대전은 `P1 키`/`P2 키`를 각 보드 옆에, P2P는 내 보드 옆에만 `내 키`를 쓴다. 화면 아래에는 공통 키(`일시정지 P · 나가기 Q` / P2P `일시정지 P · 기권 Q 두 번`)와 범례만 남긴다.
- 근거: `BattleKeyGuideTest`, 화면 `build/verification/s12-b1-battle-local.png`, `s12-b1-battle-client.png`.

### 사람이 해야 남는 확인

- 실제 키보드로 공식 ZIP을 두 PC에서 실행해 로컬 한 판·P2P 한 판 (OS 키 반복·IME·실제 배율). 자동 인수는 Swing 키 이벤트 주입까지만 확인한다.

## 2. S12-B2 시연 동선 (3~5분)

| 시간 | 화면 | 하는 일 | 보여 줄 것 |
|---|---|---|---|
| 0:00 | 메인 메뉴 | ↓로 `대전` → Enter | 시작 메뉴에서 대전 진입 (R3-MENU) |
| 0:20 | 대전 메뉴 | `로컬 아이템 대전` | 3모드 선택 (R3-MODES) |
| 0:30 | 로컬 경기 | 두 사람이 보드 옆 키 안내를 보고 조작, 2줄 이상 지워 공격 | 공격 대기열 n/10, 회색 X 줄 (R3-ATTACK, R3-CAP) |
| 1:30 | 로컬 경기 | P로 일시정지 → 다시 P | 두 보드가 함께 멈춤 |
| 1:45 | 결과 | Q로 나가기 → 기권 선택 → 결과 → Enter | 결과만 표시, 스코어보드 저장 없음 (R3-NOSCORE) |
| 2:00 | P2P 로비 (PC A) | `호스트로 대기`, 화면에 뜬 IP·포트 안내 | 같은 LAN 접속 안내 |
| 2:15 | P2P 로비 (PC B) | `최근 IP`에서 고르거나 IP 입력 → `접속` | 최근 IP 저장 (R3-RECENT) |
| 2:30 | 로비 | 호스트가 `시간제한 대전` 선택, 양쪽 `게임 시작` | 호스트만 모드 선택, 양쪽 준비 (R3-READY) |
| 2:45 | P2P 경기 | 각자 `내 키`로 조작 | 두 PC 모두 양쪽 보드·점수·남은 시간 (R3-LIVE, R3-TIME) |
| 3:45 | 결과 | 시간 종료 → 각 PC에 `승리!`/`패배` → Enter `다시 대전` | 같은 연결로 재대전 (R3-REMATCH) |
| 4:15 | 장애 | 한쪽 랜선 분리 또는 창 닫기 | 지연 표시 → `상대와 연결이 끊어졌습니다`(LOST) 또는 `상대가 나갔습니다`(PEER_LEFT) 후 P2P 첫 화면 (R3-LAG, R3-DISCONNECT) |

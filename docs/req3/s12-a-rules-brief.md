# S12 A 트랙: 엔진 후보 동결 검증(S12-A1)과 대전 규칙 설명·대표 선수 연습 자료(S12-A2)

작성: 2026-11-14. 1장은 실제 실행 결과, 2~3장은 설명 자료, 4장은 **실제 진행 후 채우는 기록 칸**이다. 4장이 비어 있으면 대표 선수 선발·연습은 아직 하지 않은 것이다.

## 1. S12-A1 엔진 후보 동결 검증

리허설에서 보고된 엔진 결함이 아직 없어서, 완료 조건의 "없으면 고위험 경계 재검증"으로 진행했다.

| 고위험 경계 | 재검증 근거 | 결과 |
|---|---|---|
| 재대전 때 전판 상태 누출 (공격·held·CLEARING·Pause·마감·sequence) | `RematchLifecycleTest` (S10-A1) | 통과, 엔진 수정 없음 |
| 공격 도착 시점·대기열 상한·상단 초과·동시 패배·마감 우선 | `AttackBoundaryEngineTest` (S10-A2) | 통과, 엔진 수정 없음 |
| 세 모드 무작위 장시간 플레이 불변식·최대 pulse 지연 | `VersusStressTest` (S11-A1) | 통과, 로컬 최대 pulse 16.7 ms 이하 |
| 1·2차 싱글 회귀 (보드 0..8) | `RandomInputStressTest` 외 기존 테스트 | 통과 |

새 테스트는 리셋·순서 코드를 일부러 지운 변형에서 실패하는 것을 확인했다(변형 6종). 전체 `check` 결과는 아래 표에 기록한다.

| 항목 | 값 |
|---|---|
| 기준 커밋 | `68fde30` (develop, S11-A2 #179 병합 직후) |
| 명령 | `gradlew check` (로컬 저메모리 init 스크립트: 힙 128 MB, 직렬 실행) |
| 결과 | BUILD SUCCESSFUL (test, jacocoTestCoverageVerification 포함), 2026-11-14 로컬 Windows 11 · JDK 25.0.2 실행 (컴파일 대상 `--release 21`) |
| 테스트 | 1,236개, 실패 0, 건너뜀 20 (guiAcceptance 전용 실제 창 테스트) |
| 라인 커버리지 | 88.27% (5,013 / 5,679줄), 게이트 70% 통과 |
| 소요 | 1분 7초 (컴파일 캐시 사용, test 태스크는 전체 실행) |

동결 기준: 이 커밋 이후 A 트랙은 리허설·두 PC 측정에서 재현된 결함 수정만 넣는다. 새 기능·도전과제는 넣지 않는다.

## 2. 30초 규칙 설명 (대표 선수·시연자용)

> 두 사람이 각자 보드에서 테트리스를 합니다. **한 번에 두 줄 이상 지우면** 지운 줄이 회색 줄이 되어 상대 보드 **아래에서 올라갑니다.** 회색 줄에는 방금 놓은 블록 모양만큼 구멍이 있어요. 보내진 줄은 먼저 상대 보드 옆 **대기열**에 쌓였다가(최대 10줄), 상대가 블록을 하나 놓은 직후 들어갑니다. 더 이상 블록을 놓을 수 없으면 집니다. 시간제한 대전은 시간이 끝났을 때 점수가 높은 쪽이 이기고, 아이템 대전은 혼자 하는 아이템 모드의 아이템이 그대로 나옵니다.

## 3. 자주 받을 질문

| 질문 | 답 | 근거 |
|---|---|---|
| 한 줄만 지우면? | 공격 없음. 두 줄 이상부터 | R3-ATTACK |
| 공격 줄 모양은? | 지우기 전 그 줄들에서 방금 놓은 블록 칸만 비운 모양. 예: O로 두 줄 → 두 줄 모두 같은 두 칸이 빈 회색 줄 | D-09, `AttackRowsTest` |
| 서로 동시에 공격하면 상쇄? | 상쇄 없음. 둘 다 상대 대기열에 들어감 | D-10 |
| 대기열이 10줄이면? | 넘치는 줄은 가장 아래부터 버리고, 이미 10줄이면 새 공격은 무시 | R3-CAP |
| 줄이 지워지는 중(하얗게 깜빡임)에 공격이 오면? | 내 줄 삭제와 점수 정산이 끝난 뒤, 다음 블록 나오기 전에 들어감 | D-11 |
| 공격이 들어와서 위로 밀려 넘치면? | 고정된 칸이 보이는 보드 위로 밀리면 패배 | D-12 |
| 둘이 같은 순간에 지면? | 무승부 | R3-LOSS |
| 시간 끝나는 순간에 졌으면? | 패배가 시간 종료보다 우선 | D-06 |
| 시간제한 동점이면? | 무승부. 시간은 180초, 아이템 없음 | D-05 (교수자 미확인 팀 기본안) |
| 아이템 대전에서 L로 지운 줄도 공격? | 자연 완성 줄과 합쳐 두 줄 이상이면 공격. 폭탄·무게추로 지운 칸은 세지 않음 | D-09 (교수자 미확인 팀 기본안) |
| 점수 2배·슬로우가 상대에게도? | 아니요, 얻은 사람에게만 | `docs/item-specification.md` 7장 |
| 대전 점수는 스코어보드에 남나? | 남지 않음 | R3-NOSCORE |
| 조작키는? | 로컬: P1 방향키·Space, P2 A/D/S/W·F, 공통 P 일시정지·Q 나가기. P2P: 각자 `내 키`, Q 두 번이 기권 | D-14, `s12-b-demo.md` |

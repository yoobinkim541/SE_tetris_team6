## 1. 한 줄 컨셉

**테트리스로 보스를 쓰러뜨린다.** 줄을 지우면 보스 HP가 깎이고, 보스는 예고한 대상에게 방해 패턴을 쏜다. 혼자(솔로), 둘이 같이(협동), 둘이 경쟁(레이스) 모두 같은 보스·패턴·연출을 쓴다.

- 기존 대전 구조 재사용: 보드 2개, 공격 줄 대기열(`PendingAttackQueue`), 아이템 효과 구조(`ItemEffect`/`GameModifiers`), 호스트 권위 P2P(`HostBattleClient`)
- 바뀌는 것: 공격 방향이 "상대 보드"에서 "보스"로, 방해가 "상대가 보낸 줄"에서 "보스 패턴"으로

## 2. 모드 3종

| 모드 | 인원 | 보스 HP | 공격 대상 | 끝나는 조건 | 기록 |
|---|---|---|---|---|---|
| **솔로 레이드** | 1 | 협동의 55% | 항상 나 | 내가 게임오버 | 처치 수 → 총 데미지 → 생존 시간 |
| **협동 레이드** ⭐ | 2 (로컬·P2P) | 100% | 어그로 규칙으로 1명 (§4.3) | 둘 다 쓰러짐 | 팀 처치 수 (팀 이름 입력, 협동 순위표) |
| **1v1 레이스** | 2 (로컬·P2P) | 솔로와 같음, 각자 자기 보스 | 각자 자기 보스에게만 맞음 | 한 명 게임오버 또는 5분 | 처치 수 → 남은 보스 HP 비율 |

- **솔로**: 협동에서 어그로·막아주기·부활·합체 필살기만 뺀다. 협동 게이지 대신 **필살 게이지**(혼자 채워 혼자 발동).
- **레이스**: 두 사람이 **같은 시드의 같은 보스**를 각자 상대한다. 먼저 잡은 사람이 **상대에게 쓰레기 줄 2줄**을 보내고(기존 공격 줄 경로 재사용), 다음 보스는 둘 다 동시에 다음 단계로. 느린 쪽 화면에는 `선수를 빼앗김`이 뜬다. 1v1 대전을 "보스라는 공통 장애물을 두고 겨루는 경기"로 바꿔 역전 여지를 만든다. 보상 카드는 넣지 않는다(10초 정지가 역전 속도를 죽인다). 어그로·막아주기·부활·합체 필살기도 없고, 필살 게이지는 솔로처럼 각자 채운다. 한 명이 상단에 닿으면 상대 승, 5분이 지나면 처치 수 → 남은 보스 HP를 깎은 비율 → 무승부.
- 기존 일반·아이템·시간제한 대전은 **규칙 그대로 둔다**(명세 준수 모드). 새 모드는 메인 메뉴 `보스 레이드` 아래에 추가.

### 3.2 패턴 상세

| 패턴 | 효과 | 지속·해제 | 막는 방법 | 구현 재사용 |
|---|---|---|---|---|
| ☁️ 구름 | 대상 보드 4×3 영역 가림 (v1의 2×2는 체감이 약해 키움) | 대상 조각 5개 | 팀원이 줄 지울 때마다 1개씩 단축 (정화) | 렌더링만 |
| 🧱 블록 소환 | 위에서 10줄 아래 빈칸에 덩어리 1개(3~4칸) 고정 | 즉시 | 예고 중 2줄 이상 지우면 취소 | 보드 칸 쓰기 + 상단 초과 판정 |
| 🪨 바위 투척 | 쓰레기 줄 2줄(Lv.4부터 3줄) | 대기열로 들어가 다음 Spawn 전에 삽입 | 막아주기로 1줄 감소, 방패로 무효 | `PendingAttackQueue` 그대로 |
| 🏛️ 기둥 | 랜덤 열 하나에 아래부터 4칸 회색 기둥 | 기둥 줄을 지우면 사라짐 | — | 무게추 아이템 칸 쓰기 응용 |
| 🦇 저주 블록 | 대상의 다음 블록 2개를 S/Z로 교체 | 즉시 | 홀드로 피할 수 있음 | `NextBlockQueue` 강제 큐 |
| 🙈 미리보기 봉인 | NEXT·HOLD 칸 가림 | 조각 4개 | — | 렌더링만 |
| ⚡ 과부하 | 낙하 속도 2배 | 조각 5개 | — | 슬로우 아이템의 반대 (`GameModifiers`) |
| 🔗 연결 공격 | 두 보드에 쓰레기 1줄씩, 사슬 이펙트 | 둘 다 1줄 이상 지우면 해제. 조각 8개 안에 못 풀면 1줄씩 더 | 협동 전용 (솔로·레이스는 바위 1줄) | 공격 줄 + 상태 플래그 |
| 🌀 반전 | 좌우 입력 반대 | 조각 3개 | — | 입력 라우터 매핑 |

- 패턴 선택: 보스의 3패턴 중 **가중 랜덤**(기본 40/40/20, 시그니처는 Lv.2부터 20%). 같은 패턴 3연속 금지.
- 색맹 모드: 모든 패턴 효과는 색만이 아니라 아이콘·무늬로도 구분 (구름=빗금, 기둥=세로줄 무늬, 저주 블록=해골 표시).

### 3.3 단계(Lv) 진행
- 한 판에서 보스를 잡을 때마다 Lv +1. 다음 보스는 **아직 안 나온 보스 중 랜덤**(4종을 한 바퀴 돌면 다시 섞음).
- Lv이 오를수록: HP ×1.3, 패턴 카운트다운 조각 수 −1(최소 4), Lv.4부터 패턴 위력 증가(위 표 참고).
- **5% 확률**로 다음 보스 대신 황금 테트로 등장(같은 판 1회).

### 3.4 단계별 강화 이미지 (v1 아이디어 유지)
- 보스마다 **Lv.1 / Lv.2 / Lv.3+** 이미지 3단계. 같은 캐릭터가 장식·오라·크기·색감이 과해지는 방향(이미지 편집으로 같은 캐릭터 유지).
- Lv.5 이상은 Lv.3 이미지에 색조 변형만.
- 밈 원본 사진은 쓰지 않는다. 직접 생성한 이미지만 쓰고 §7.4의 출처 표에 남긴다.

### 4.2 보스 HP와 예상 처치 시간
- 근거: NORMAL 기준 한 사람이 분당 약 12~16줄, 줄당 평균 약 12 데미지 → 2인 분당 약 340 데미지.

| Lv | 협동 HP | 솔로·레이스 HP (55%) | 협동 예상 |
|---|---|---|---|
| 1 | 300 | 165 | 약 55초 |
| 2 | 390 | 215 | 약 70초 |
| 3 | 505 | 280 | 약 90초 |
| 4 | 660 | 365 | 약 2분 |
| 5+ | ×1.3씩 | ×1.3씩 | |

- 첫 플레이테스트 후 Lv.1 처치가 40~70초 범위를 벗어나면 HP만 조정.

### 4.3 공격 주기와 어그로 (협동)
- 패턴은 **대상이 조각 N개를 놓으면** 발동. Lv.1 N=8(약 15초) → Lv마다 −1, 최소 4.
- 다음 대상은 직전 패턴 발동 순간 정해 **바로 예고**(가운데 문구 + 대상 보드 빨간 테두리 + 남은 조각 수).
- 대상 선택: 기본은 번갈아. 단, 최근 30초 데미지 비율로 기울임
  `P(대상=P1) = 0.5 + 0.3 × (딜P1 − 딜P2) / (딜P1 + 딜P2)` (0.2~0.8로 제한). 한 명만 몰아서 딜하면 그 사람이 더 자주 맞는다.
- 한 명이 쓰러져 있으면 살아 있는 사람만 노린다.

## 5. 운 요소 (카톡 11/20: "운빨 요소가 있어야 함")

모든 난수는 판 시작 때 정한 **시드 하나**에서 뽑는다 → 로컬·P2P 모두 같은 결과, 엔진 테스트도 고정 시드로 결정적.

1. **보스 등장 순서·패턴 선택**: 위 §3.2·§3.3.
2. **럭키 블록**: 10조각 중 1개꼴로 금테 블록이 나온다. 그 블록 칸이 포함된 줄을 지우면 **크리티컬 ×2** ("CRITICAL!" 연출). 실력(그 블록으로 줄을 만들기)과 운이 섞임.
3. **처치 보상 카드**: 보스를 잡을 때마다 카드 3장이 랜덤으로 뜨고 1장 선택(협동은 번갈아 선택권). 10초 안에 안 고르면 가운데 카드.

| 카드 | 효과 |
|---|---|
| 🗡️ 날카로운 블록 | 이번 판 데미지 +10% (중첩) |
| 🛡️ 방패 | 다음 패턴 1회 무효 |
| ⏳ 시간 왜곡 | 다음 보스의 첫 패턴 카운트다운 +4 |
| 💛 응원 | 협동/필살 게이지 +50 |
| 🔭 망원경 | NEXT 미리보기 +2 (최대 5) |
| 🍀 행운 | 럭키 블록 확률 2배 (보스 1마리 동안) |
| 🧹 대청소 | 내 보드 맨 아래 2줄 즉시 제거 |

4. **황금 테트로**: §3.1. 희귀 등장 자체가 시연 때 반응 포인트.

## 6. 게임성을 해치던 요소와 해결

현재 동작은 1차 명세 v1.2의 팀 결정(Lock Delay 없음 LCK-1, Ghost 표시 안 함, OS 키 반복, 시계 방향 회전만, Wall Kick 없음)을 따른다. 명세상 맞지만 실제 테트리스와 비교하면 손맛을 크게 해친다. **challenge 빌드에서는 설정 `조작 방식: 클래식(명세) / 모던`을 두고 모던을 기본값**으로 한다(명세 준수 확인이 필요하면 클래식으로 전환).

| 문제 | 지금 | 해결 (모던) | 담당·상태 |
|---|---|---|---|
| 착지 즉시 고정 | Lock Delay 없음 | 착지 후 0.5초, 이동·회전 시 초기화 최대 15회 | 규민 님 `feature/t-spin-lock-delay` 커밋 `64b1781` (develop 이전 기준이라 리베이스 필요) |
| 벽 옆 회전 실패 | 충돌하면 회전 취소 | SRS Wall Kick | 같은 브랜치 `b13363b` |
| 고급 기술 보상 없음 | 없음 | T-스핀 판정 → 레이드 데미지 ×1.5 | 같은 브랜치 |
| 착지 위치를 알 수 없음 | Ghost 없음 | 반투명 Ghost 블록 | 신규 (렌더링만) |
| 한 방향 회전 | 시계 방향만 | 반시계 회전 추가 | 신규 |
| 나쁜 블록을 피할 방법 없음 | Hold 없음 | Hold 1칸 (한 조각에 1회) | 신규 |
| 좌우 이동이 OS 설정에 좌우됨 | OS 키 반복 | DAS 150ms / ARR 33ms 자체 타이머 (설정에서 조절) | 신규 |
| 앞을 계획하기 어려움 | NEXT 1개 | NEXT 3개 | 신규 (`NextBlockQueue`는 이미 개수 설정 가능) |
| 줄 삭제 후 멈칫함 | 삭제 표시 150ms 동안 입력 대기 | 유지하되 그동안 들어온 입력을 버리지 않고 다음 블록에 적용 (입력 버퍼) | 신규 |

## 7. UI/UX 업그레이드

### 7.1 아트 방향
- 톤: **밤하늘 판타지 아케이드**. 어두운 남색 우주 배경 + 네온 테두리 패널 + 보석처럼 빛나는 블록. 보스는 귀엽지만 위협적인 캐릭터(시연 관객 반응용).
- 가독성 우선: 보드 뒤는 어둡고 단순하게, 화려함은 보드 바깥(배경·보스 영역)에만.

### 7.2 "쉴새 없이 움직이는 배경 — 별똥별" 가능한가? → **가능**
- 배경 그림 1장(정지 이미지) 위에 **별똥별·반짝이는 별·떠다니는 먼지를 코드로 그린다**(입자 수십 개, 매 프레임 위치만 갱신). 동영상이 아니라서 용량이 거의 늘지 않는다.
- 3겹 시차: 먼 별(느림) → 성운 이미지(정지) → 별똥별(빠름). 보스가 패턴을 쓰면 배경 색조가 잠깐 바뀐다.
- 성능: 배경 이미지는 화면 크기에 맞춰 **한 번만 스케일해 캐시**, 입자는 단순 선·점. 저사양 대비 설정 `연출: 높음/낮음`(낮음은 입자 끔).

### 7.3 연출 (손맛)
- 줄 삭제: 줄이 빛나며 조각나는 파티클, 보드 살짝 흔들림(4줄은 크게)
- 데미지: 보드에서 보스로 날아가는 빛줄기 + 보스 피격 흔들림·하얀 번쩍임 + 데미지 숫자 팝업
- 콤보·T-스핀·크리티컬·"PERFECT" 큰 문구
- 보스 예고: 대상 보드 빨간 테두리 맥동 + 남은 조각 수 큰 숫자, 발동 직전 경고음
- 협동: 막아주기 방패 이펙트, 부활 진행 링, 합체 필살기 3초 컷인(두 보드에서 빛줄기가 합쳐짐)
- 보스 처치: 슬로모션 0.5초 + 폭발 + 보상 카드 뒤집기
- 효과음 약 15종 + 배경음 1~2곡(무료 상업 이용 가능 CC0 음원), 설정에서 음량·끄기

## 8. 구현 구조

### 8.1 엔진 (Swing 의존 없음, 고정 시드 테스트)
```
RaidEngine (호스트에서만 실행, 16ms pulse — LocalMatchEngine과 같은 방식)
 ├─ GameSession ×1~2          기존 세션 재사용 (+ 모던 조작 정책)
 ├─ BossDirector              시드, 보스 순서, Lv, HP, 카운트다운, 대상 선택
 │   └─ Boss → BossPattern ×3 패턴 인터페이스 (ItemEffect와 같은 모양: apply / onPiecePlaced / isExpired)
 ├─ AggroPolicy               §4.3 공식
 ├─ CoopState                 게이지, 부활 진행, 동시 공격 창
 ├─ RewardDeck                카드 제시·선택
 └─ RaidSnapshot              MatchSnapshot + boss(id, lv, hp, maxHp, nextPattern, target, piecesLeft) + 효과 목록 + 카드
```
- 줄 삭제 데미지는 기존 `LockResult.clearedRows`에서 계산 → 엔진 변경 최소.
- 쓰레기 줄 패턴은 기존 공격 줄 대기열로 넣는다(삽입 시점·상단 초과 패배 규칙 그대로).

### 8.2 P2P (협동·레이스)
- 지금처럼 **호스트가 엔진을 돌리고**, 클라이언트는 입력만 보낸다. 대전 `STATE`와 섞지 않고 `RAID_INPUT`·`RAID_STATE`·`RAID_RESULT`를 쓴다. 송신 간격은 대전 STATE와 같다(최대 30Hz). 스냅샷은 보드·보스·효과·사건만 실어 64KiB 안에 둔다.
- 로비 CONFIG에 `raid=COOP|RACE`를 더한다. 없으면 기존 대전. READY/START·재대전·끊김은 대전 로비를 그대로 쓴다. 호스트 모드 목록은 대전 3종 + 협동 레이드 + 레이스 레이드.
- 프로토콜 버전(`WireFormat.VERSION`)을 올려 기존 빌드와 섞이면 접속 단계에서 거부. 중계의 `proto`도 이 값을 본다.
- 클라이언트는 자기 키를 P2 입력으로 보내고, 화면 오른쪽이 나다. 필살은 R.

### 8.3 화면
- `RaidPanel`: 기존 `BoardRenderer` 재사용 + 보스 영역 + 효과 레이어
- `AssetStore`: 이미지 로드·화면 크기별 캐시, 실패 시 지금 같은 단색 그리기로 대체(에셋이 없어도 게임은 돈다)
- `FxLayer`: 파티클·흔들림·팝업 문구, `Sound`: `javax.sound.sampled` WAV 재생

## 12. 완료 기준 (시연 최소 단위)

- 솔로: 메뉴 → 보스 2종 이상을 잡으며 Lv 상승 → 게임오버 → 기록 표시까지 멈춤 없음
- 협동(로컬): 예고 → 막아주기 성공 → 한 명 쓰러짐 → 부활 → 합체 필살기 → 처치가 한 판 안에서 모두 보임
- 모던 조작: Ghost·Hold·반시계·Wall Kick·Lock Delay 동작, `클래식`으로 바꾸면 기존 동작
- 배경 별똥별이 계속 움직이고, 화면 크기 3종에서 잘리지 않음
- 기존 테스트 전부 통과 + 레이드 엔진 고정 시드 테스트 + GUI 인수 테스트

# 교수자 확인 요청 문안

상태: **초안 준비 / 미발송 / 미답변**. 사용자 요청에 따라 문안을 준비했으며 교수자 승인으로 간주하지 않는다.

## 문의 제목

소프트웨어공학 Team 6 테트리스 구현·배포 요구사항 해석 확인 요청

## 문의 본문

안녕하세요 교수님. Team 6 테트리스 프로젝트 구현 기준과 관련해 다음 사항을 확인 부탁드립니다.

1. **Q1 — 텍스트 기반 표현:** Swing GUI 창에서 각 블록 칸에 문자와 색상을 함께 표시하는 구현도 인정되는지, 별도 콘솔 구현이 필요한지 궁금합니다.
2. **Q2 — 보드 크기 3종:** 게임 논리 보드는 요구사항의 20행×10열을 유지하고 Small/Medium/Large 셀 표시 크기를 제공하고 있습니다. 이를 크기 3종으로 인정할 수 있는지, 실제 행·열 수가 서로 달라야 하는지 확인 부탁드립니다.
3. **Q4 — 배포 형식:** Windows EXE와 Java 런타임을 포함한 jpackage app-image를 ZIP으로 제공하여, 압축 해제 후 Java 별도 설치 없이 실행하도록 구성했습니다. 이 형식으로 제출 가능한지, MSI/설치형 EXE가 별도로 필요한지 확인 부탁드립니다.
4. 요구사항 2의 최종 제출일·제출 위치와 실제 사용자 2명 평가 기록의 필수 제출 형식도 안내 부탁드립니다.

감사합니다.
